## 🎨 ЧАСТЬ 1: Вёрстка и Адаптив (Max: 100 баллов)  


### 1. Страницы и навигация (10 баллов)  
[ ] Две страницы: index.html (Главная) и products.html (Каталог) с разными URL.  
[ ] Переходы: Клик по логотипу/названию ведет на Главную; с любой страницы можно перейти на другую.  
[ ] Якорные ссылки: Навигация по секциям с плавным скроллом (scroll-behavior: smooth).  
### 2. Структура и Секции (25 баллов)  
[ ] Header: Единообразный на обеих страницах (Логотип, Навигация nav > ul > li > a, Переключатель темы, Кнопка бургер-меню для $\le$ 768px).  
[ ] Главная страница (не менее 4-х секций):  
[ ] Hero-секция (заголовок h1, инфо, CTA-кнопка).  
[ ] Слайдер/Карусель (минимум 3 слайда + стрелки управления).  
[ ] Ещё минимум 2 контентные секции по макету.  
[ ] Каталог (Coffee House):  
[ ] 3 категории переключения (Coffee, Tea, Dessert).  
[ ] Элементы управления категориями (табы/кнопки).  
[ ] Минимум 8 карточек в базовой категории (картинка, заголовок, описание, цена).  
[ ] Кнопка показа оставшихся карточек («Load More»).  
[ ] Footer: Единообразный на обеих страницах (контакты, соцсети/карты рабочими ссылками).  
### 3. Светлая и тёмная темы (17 баллов)  
[ ] Переключатель темы корректно меняет стили всех секций обеих страниц.  
[ ] Состояние переключателя соответствует активной теме.  
[ ] Активная тема сохраняется в localStorage и восстанавливается при перезагрузке и переходе между страницами.  
[ ] Контраст и читаемость сохраняются в обеих темах.  
### 4. Адаптивность и Верстка (33 балла)  
[ ] Проверяемые брейкпоинты: 1440px, 768px, 380px (и промежуточные).  
[ ] При плавной растяжке від 1440px до 380px: нет горизонтального скролла, контент не вылезает и не обрезается, картинки сохраняют пропорции.  
[ ] При $>1440\text{px}$: контент центрируется и огранивается по ширине.  
[ ] При $\le 768\text{px}$: основная навигация скрывается, появляется кнопка бургер-меню.  
[ ] Семантика: один h1 на страницу, логичная иерархия заголовков (h1 $\rightarrow$ h2 $\rightarrow$ h3), корректные alt у изображений.  
[ ] Интерактив: плавные hover-состояния у ссылок/кнопок без сдвига соседних элементов.  


## ⚡ ЧАСТЬ 2: Интерактив и JS (Max: 100 баллов)  


### 1. Данные каталога (10 баллов)  
[ ] Карточки и данные модалок генерируются динамически из products.json.  
[ ] Нет дублирования данных в HTML (один источник правды).
### 2. Бургер-меню (20 баллов)[ ] Работает на ширине $\le 768\text{px}$ на обеих страницах.  
[ ] Плавное открытие/закрытие по клику, иконка меняется на крестик.  
[ ] Блокировка скролла страницы при открытом меню.[ ] Закрытие по клику на любую ссылку, на оверлей или по клавише Escape.  
[ ] Авто-закрытие и возврат дефолтной навигации при ресайзе экрана $> 768\text{px}$.  
### 3. Слайдер / Карусель на Главной (20 баллов)  
[ ] Кнопки «Вперёд» / «Назад» переключают слайды.[ ] Циклическое бесконечное переключение.[ ] Плавная анимация смены слайдов.  
[ ] Индикаторы (пагинация/полосы) синхронизированы с текущим слайдом.  
[ ] Корректная работа при ресайзе окна (1440px, 768px, 380px).  
### 4. Переключение категорий в Каталоге (12 баллов)  
[ ] По умолчанию при загрузке активна первая категория (Coffee).  
[ ] При клике на другую категорию фильтруются карточки без перезагрузки страницы.  
[ ] Визуальное выделение только одной активной кнопки категории.  
### 5. Отображение карточек и «Load More» (13 баллов)  
[ ] При $>768\text{px}$: отображаются сразу все карточки категории.  
[ ] При $\le 768\text{px}$: сначала видны 4 карточки + кнопка показа оставшихся.  
[ ] По клику на кнопку открываются остальные карточки, а сама кнопка скрывается.  
[ ] При смене категории список сбрасывается в начальное состояние.  
### 6. Модальное окно товара (12 баллов)  
[ ] Открывается по клику на любую часть карточки.  
[ ] Центрируется, затемняет задний фон (оверлей).  
[ ] Блокирует скролл страницы.  
[ ] Закрывается по клику на крестик, на оверлей или по Escape (клик внутри окна не закрывает).  
[ ] Корректно выглядит на 1440px, 768px, 380px в обеих темах.  
### 7. Параметры товара в Модалке (13 баллов)  
[ ] Содержит минимум 2 параметра выборки (например: размер порции / добавки).  
[ ] Клик по параметрам меняет их активное состояние.  
[ ] Динамический пересчёт связанной информации (например, итоговой цены) на лету.  
[ ] При открытии любой карточки модалка корректно заполняется соответствующими исходными данными из JSON.
